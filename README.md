# RUA 2026

This is a Next.js web application built for RUA (Royal University of Agriculture) 2026. It features a modern layout with responsive design, including a Hero section, Video Player, Photo Gallery, and an About section.

## 🚀 Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Styling**: Custom CSS Modules with responsive design
- **Animations**: Framer Motion & custom scroll reveals
- **Icons**: React Icons

## 📂 Project Structure

- `app/` - Next.js routing, layout, and global CSS (`globals.css`)
- `components/` - Reusable UI components (`Navbar`, `Hero`, `Gallery`, `VideoPlayer`, `About`, `Footer`)
- `public/` - Static assets like images and the RUA logo

## ✨ Features

- **Modern UI/UX**: Clean and professional design tailored for academic showcase.
- **Responsive Layout**: Optimized for both desktop and mobile viewing.
- **Scroll Animations**: Smooth reveal effects as users scroll down the page.
